Cómo trabajo

Uso Claude Code como herramienta, con reglas que escribí yo: skills propias, un hook que bloquea comandos destructivos, revisiones de seguridad y rendimiento antes de publicar, commits convencionales e integración continua. Lo que está en mi código lo sé explicar.

I design the solution, review every change and decide what gets merged. I use Claude Code as a tool, under rules I wrote: my own skills, a hook that blocks destructive commands, security and performance reviews before shipping, conventional commits and CI. I can explain everything in my code.
