## Sobre el Proyecto

Este es mi portafolio personal web, diseñado para presentar mi perfil profesional, habilidades técnicas, educación y aspiraciones como desarrollador en formación. El sitio cuenta con un diseño moderno, minimalista y completamente responsivo, con animaciones interactivas que mejoran la experiencia del usuario.

### ¿Por qué este proyecto?

-  **Presentación profesional**: Mostrar mis habilidades y experiencia de forma atractiva
-  **Aprendizaje continuo**: Aplicar y mejorar mis conocimientos en desarrollo web
-  **Marca personal**: Establecer mi presencia online como desarrollador
-  **Networking**: Facilitar el contacto con reclutadores y colaboradores

##  Características

###  Diseño y UX

-  **Diseño moderno y minimalista** con esquema de colores oscuros (dark theme)
-  **Totalmente responsivo** - Compatible con dispositivos móviles, tablets y desktop
-  **Animaciones fluidas** al hacer scroll y al cargar las secciones
-  **Transiciones suaves** entre secciones con navegación intuitiva
-  **Efectos visuales interactivos** en hover y al interactuar con elementos

###  Funcionalidades Técnicas

-  **Navegación por anclas** con desplazamiento suave (smooth scroll)
-  **Intersection Observer API** para animaciones al entrar en viewport
-  **Barras de progreso animadas** para visualizar nivel de habilidades
-  **Efectos de parallax** en el header
-  **Animación de tipeo** en el logo
-  **Optimización de rendimiento** sin dependencias pesadas
-  **SEO-friendly** con metadatos apropiados

###  Efectos Especiales

- Gradientes animados en el header
- Efecto glow en elementos destacados
- Animaciones fade-in al hacer scroll
- Cambio dinámico de sombras según dirección del scroll
- Efecto de mouse tracking en el header

##  Instalación

### Requisitos Previos

- Un navegador web moderno (Chrome, Firefox, Safari, Edge)
- Editor de código (VS Code, Sublime Text, etc.) - opcional
- Servidor local (opcional, pero recomendado)

### Opción 1: Descarga Directa

1. **Clona el repositorio**
   ```bash
   git clone https://github.com/SantiagoRicaurte06/Portafolio.git
   ```

2. **Navega al directorio**
   ```bash
   cd Portafolio
   ```

3. **Abre el archivo index.html**
   - Doble clic en el archivo
   - O arrastra el archivo a tu navegador

### Opción 2: Usando un Servidor Local

**Con Python:**
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

**Con Node.js (http-server):**
```bash
npx http-server -p 8000
```

**Con Visual Studio Code:**
- Instala la extensión "Live Server"
- Click derecho en `index.html` → "Open with Live Server"

4. **Accede al sitio**
   - Abre tu navegador en `http://localhost:8000`
