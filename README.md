# Portafolio · Santiago Alexis Ricaurte

Portafolio personal con estética japonesa en blanco y negro: una casa de puertas shōji que se recorre con la luz de una linterna andon, con caligrafía trazada en cada sección.

En construcción.

## Ejecutar en local

Es un sitio estático: abre `index.html` en el navegador o sirve la carpeta con cualquier servidor estático.
